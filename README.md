## 📌 About the Internship

The internship focused on planning and designing an **e-commerce web platform for the apparel and textiles industry**. It followed a structured, project-based approach covering project planning, competitor research, front-end UX design, back-end architecture and API planning, testing, and performance evaluation.

The proposed platform focuses on a mobile-first shopping experience with product search and filtering, cart and checkout functionality, payment integration, inventory management, user accounts, and order tracking.

---

## 🎯 Objectives

- Design a responsive apparel & textiles e-commerce platform
- Provide intuitive product categorisation, search, and filtering
- Plan secure cart, checkout, and payment functionality
- Enable real-time inventory tracking
- Optimise the platform for mobile users
- Establish a scalable technical foundation
